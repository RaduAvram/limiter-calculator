Detailed breakdown
How it works
  • Each system's continuous and peak ceilings come from its speaker ratings and the amp's full-power voltage. The peak check uses the crest factor plus the PA2's roughly 3 dB overshoot.
  • The venue limit adds both systems' sound at the measurement point, power-summed. If the total is too high, both thresholds drop by the same amount until it fits.
  • The threshold is set where each amp reaches full power. The nominal input sets only the headroom display.
  • With a 2× peak rating the RMS limit sits about one crest factor below the continuous limit. To reach the continuous rating, the peak rating needs to be roughly the crest factor plus 3 dB above continuous.
  • Summed driver ratings are optimistic for passive cabinets, since each driver's own limit at the crossover can be lower. Confirm the cabinet's peak rating if you can.
  • The PA2 scale assumes 0 dBFS = +20 dBu at the output. The PA2 output tops out at that level, so amps that need more are flagged.
  • The venue calculation assumes free-field distance falloff (6 dB per doubling). Indoors, reflections raise the level, so measure and adjust the correction.
  • Mono sum level is not modelled. If you sum L and R into one bass feed without a pad, the feed is up to 6 dB hotter, so lower the bass threshold by that amount.
  • Over Easy changes the knee shape, not this math. Use the 3 dB overshoot margin when you run it hard.
Notes and sources
  • Olive cabinet: Beyma 10CMV2 woofer, 8 Ω, 250 W AES / 500 W program, 95 dB 1 W/1 m. Beyma SMC-8060 tweeter, 8 Ω, 107 dB 1 W/1 m, reduced by a 12 dB pad, which brings it close to the woofer's level. The cabinet uses 95 dB. The SMC-8060 without /N is taken to have the same power rating as the /N.
  • Olive power is the sum of the two drivers' ratings: 300 W continuous (250 + 50), 600 W peak (500 + 100).
  • Large top: JBL 2226H woofer (97 dB) plus Beyma CP650Ti (110 dB). The sensitivity uses the JBL figure only, so the real cabinet level is probably higher.
  • Bass: Dynacord SRC 400 LO, 800 W rated, 1600 W program, 4 Ω, 100 dB. The 1600 W is a program rating, so the peak check is conservative.
  • Bass amp: Outline T6.5, 950 W / 1700 W / 3000 W at 8 / 4 / 2 Ω, 38.2 dB gain, 1.12 V sensitivity. Full-range amp: Dynacord L2400, 2 × 750 / 1200 / 1500 W at 8 / 4 / 2 Ω, 26 dB constant-gain mode.
  • PDF check values (continuous basis, no venue limit, pots at 0 dB): sub −0.9 dBu, top +13.0 dBu with the JBL's 600 W alone (680 W summed gives +13.5 dBu). With the T6.5 pot at −18 dB, the sub becomes +17.1 dBu. PA2: 0 dBFS = +20 dBu max output.
