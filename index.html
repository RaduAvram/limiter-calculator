How it works
  • The speaker's continuous limit is V = √(P × Z). The amp's full-power voltage is found the same way from its power into the speaker's impedance.
  • Peak power means the instantaneous peak, V²/Z. For a sine wave that is twice the RMS power, which is why "2× continuous" is the usual peak rating.
  • The PA2 limiter detects RMS, has a fixed ∞:1 ratio, and can overshoot by about 3 dB. The peak check uses the crest factor plus that overshoot.
  • The venue limit assumes free-field inverse-square falloff (6 dB per doubling of distance). Indoors, reflections raise the level, so measure at the venue and adjust the correction.
  • The PA2 scale assumes 0 dBFS = +20 dBu at the output. The amp's full-power point is taken from its input sensitivity and attenuator cut.
  • Over Easy changes the knee shape, not this math. Use the 3 dB overshoot margin when you run it hard.
  • The PA2 has one limiter per output band. Run this once for each band, using that band's amp and speaker.
